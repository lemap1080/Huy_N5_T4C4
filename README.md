## About The Project

This is a personal project built for a school course named Hut Coffee.

Hut Coffee is a project that serves:
- Coffee
- Fruit tea
- Various types of fast food

![Project Overview](https://texascoffeeschool.com/wp-content/uploads/2021/12/DSC_0059-scaled.jpg)
